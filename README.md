# FF Gaming Assistant Panel

A modern, dark-themed Windows desktop application for managing BlueStacks and optimizing your mobile gaming experience.

## 🚀 Features
- **BlueStacks Manager**: Detects installation, checks status, and launches the emulator.
- **Gaming Dashboard**: Clean UI with status indicators.
- **Key Binding Reference**: Displays recommended controls for FPS games.
- **Standalone EXE**: Builds into a single executable via GitHub Actions.
